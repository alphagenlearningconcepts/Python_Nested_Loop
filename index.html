Core Concept

What is a Nested Loop? 🧱

OUTER LOOP (Rows) row = 0
INNER LOOP (Columns) col = 0

Runs COMPLETELY across all columns (0 ➔ 1 ➔ 2) for EVERY single row!

Like fixing a Lego block inside another Lego block!
Execution Light Tracer Ready to trace left-to-right!
Col 0 Col 1 Col 2

Watch the yellow light step through columns (left-to-right) for each row!

RULE: For every 1 row turn of Outer Loop, Inner Loop completes ALL column turns left-to-right!
Interactive Playground

Print a Square Pattern 🔲

Role Breakdown
  • • Outer Loop: Counts rows (vertical lines)
  • • Inner Loop: Counts columns & prints symbol horizontally
  • • print() after inner loop: Moves to the NEXT line!
for row in range(4):
  for col in range(4):
    print("⭐", end=" ")
  print() # Moves to next line

Pattern Discovery

Printing Right-Angled Triangles 📐

Triangle Output Height: 4
⭐
⭐ ⭐
⭐ ⭐ ⭐
⭐ ⭐ ⭐ ⭐

Notice the key pattern in a right triangle:

Row 1 (row=1) ➔ prints 1 star (col=1)
Row 2 (row=2) ➔ prints 2 stars (col=1, col=2)
Inner loop upper bound depends on current row number!
4
for row in range(1, 5):
  for col in range(row): # Inner loop relies on outer row!
    print("⭐", end=" ")
  print()
GOLDEN RULE: Pass row into the inner loop range so it grows on every line!
